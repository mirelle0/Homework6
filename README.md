# Домашнее задание к работе 6

## Условие задачи

Дано число N (N<1000). Написать программу, которая проверяет является ли его сумма цифр двухзначным числом.

## 1. Алгоритм и блок-схема
### Алгоритм
```
1. Начало
2. Ввести N
3. Если N < 0 или N >= 1000:
   - Вывести ошибку
   - Конец
4. sum = N % 10 + (N / 10) % 10 + N / 100
5. Если sum >= 10 и sum <= 99:
   - Вывести "двузначное"
   Иначе:
   - Вывести "не двузначное"
6. Конец
```

## 2. Реализация программы
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main() 
{
    setlocale(LC_ALL, "RUS");
    int N, sum;
    printf("Введите число N (N < 1000): ");
    scanf("%d", &N);
    if (N >= 1000 || N < 0) {
        printf("Ошибка: N должно быть в диапазоне 0 <= N < 1000\n");
        return 1;
    }
    sum = N % 10 + (N / 10) % 10 + N / 100;
    if (sum >= 10 && sum <= 99) {
        printf("Сумма цифр = %d — двузначное число\n", sum);
    }
    else {
        printf("Сумма цифр = %d — не двузначное число\n", sum);
    }
    return 0;
}
```
